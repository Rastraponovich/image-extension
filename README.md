# Pro Image Cropper

Chrome-расширение для интерактивного кадрирования изображений: загрузка файла или выбор картинки по ПКМ на странице, настройка aspect ratio, поворот, отражение, экспорт в PNG/JPEG/WebP.

## Сборка

```bash
npm install
npm run build
```

Артефакты сборки — в папке `dist/`.

## Скачать сборку

Готовую сборку можно скачать со вкладки **Releases** в репозитории: выберите нужный тег (например, `v1.0.0`), скачайте архив `image-cropper-vX.X.X.zip`, распакуйте его и в Chrome загрузите папку `dist/` как распакованное расширение (см. ниже). Новый релиз создаётся при пуше тега вида `v*` (например, `git tag v1.0.0 && git push origin v1.0.0`).

## Установка в Chrome

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. Нажмите «Загрузить распакованное расширение» и выберите папку `dist/`

## Разработка

- `npm run dev` — сборка в режиме watch (после изменений перезагрузите расширение в `chrome://extensions`)
- `npm run format` — форматирование кода Prettier
- `npm run format:check` — проверка форматирования без изменений
- `npm run lint` / `npm run lint:fix` — проверка и автоисправление кода ESLint
- `npm run check` — format:check + lint перед коммитом

## Структура

- `src/` — исходники: манифест, popup (HTML/CSS/TS), background (service worker)
- `dist/` — результат сборки (генерируется при `npm run build`)
